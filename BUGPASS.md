## Needs review (not changed: design, data-safety or uncertain)

- **NR-1 Old Markdown mirror can destroy notes (highest priority).** `DataSettingsPane.swift:286-318` always offers "Delete Plaintext Mirror", but `AppSession.resolveVaultItem` (`AppSession.swift:1598`) has no caller, so notes that exist only in the mirror, or differ from the store, can only be removed. `deleteLegacyVault` (`AppSession.swift:1610-1614`) then removes all of `Vault/`. `VaultReconciliation.scan` (`MarkdownExportService.swift:175-181`) silently skips subfolders, non-`.md` files and symlinks without reporting them, so those are deleted unseen. Needs a product decision: a per-note import action, or blocking delete while items are unresolved. [chunk 10 F7; chunk 5 F2]
- **NR-2 Editors can duplicate synced items.** `EventDetailView.swift:76-78` and `TodoDetailView.swift:76-90`: the keep-edits branch keeps a draft whose Apple link fields (`ekEventIdentifier`, `reminderIdentifier`, `syncStatus`, `lastSyncDate`) are stale. Saving then unlinks the synced copy and the next pass imports it as a duplicate. Reporter's suggested fix copies those fields from the store into draft and original; it spans sync code, so not applied. [chunk 8 F2]
- **NR-3 Todo Completed tick commits all unsaved edits.** `TodoDetailView.swift:158-161`: `setCompleted` calls `session.save(draft)` with the whole draft, so Cancel afterwards is misleading (the store already has the other edits). Needs a completion-only write path (`AppSession` + `Database`). [chunk 8 F1]
- **NR-4 Migration can lose the store after power loss.** `StoreMigrator.swift:287-304` moves `mednotes.db` to `Plaintext.old.db` before the staged database is moved in. A crash in between leaves no `mednotes.db`; on next launch `inspect` returns `.empty` and a new empty store is created. The journal (`migration.json`) is written but never read at launch (`readJournal` is only used by a test). Design work: check the journal at launch. [chunk 13 F1]
- **NR-5 Attachment/archive races.** `Services.swift:46-48` and `:283-286`: `setArchived` rewrites the whole record with `savePatient` (no attachment-reference guard), interleaving with `save`. Fix needs a targeted `UPDATE` in `Database.swift`. [chunk 5 F1]
- **NR-6 (FIXED, see Fixed #21) Lock-time patient save skipped the attachment guard.** `AppSession.swift:1060` (draft enum in `OpenEditorDraft.swift:16`): `saveDrafts` calls `patients.save(patient)` without `knownFileIDs`, so a second window's attachment can be deleted at lock. [chunk 5 F7]
- **NR-7 Keychain key path may fail outside a provisioned build.** `KeyManager.swift:106` uses `kSecUseDataProtectionKeychain`; `MedNotes.entitlements` has no `keychain-access-groups` or `application-identifier`, and Debug/Release are ad-hoc signed with `DEVELOPMENT_TEAM = ""`. Possible `errSecMissingEntitlement` (-34018) on a non-preview launch. Not verified at runtime; the owner's release/signing setup decides. [chunk 16 F1]
- **NR-8 `PRAGMA defensive = ON` is a no-op.** `Database.swift:92`: SQLite has no `defensive` pragma; defensive mode needs `sqlite3_db_config(SQLITE_DBCONFIG_DEFENSIVE)` through a C shim. The comment's claim is false. Needs a decision (shim or delete line + comment). [chunk 13 F2]
- **NR-9 Markdown decoder strips leading blank lines of note content.** `MarkdownExportService.swift:247-248`: `.drop(while: { $0.isNewline })` also removes content that starts with newlines. The retired writer's format is not in the repo, so the fix is unverified. [chunk 5 F5]
- **NR-10 Settings › General shows "Store: Plaintext" in some encrypted states.** `SettingsView.swift:21` uses `session.isReady`, which does not reflect `needsRecovery` or `initError`. Proper fix publishes whether bootstrap found a plaintext store. [chunk 10 F6]
- **NR-11 Templates pane may resurrect a reverted edit.** `TemplatesSettingsPane.swift:135-144`: on disappear, the draft is saved in the background but `original` and `templates` are not updated. Whether this happens depends on SwiftUI keeping the pane's `@State` across tab switches (not verified). [chunk 10 F4]
